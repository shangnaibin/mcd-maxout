它是怎么算的，凭什么说「最多」
先把每个套餐按轮次展开成所有可选项组合（这家门店共 — 个套餐变体）， 得到一个「购买单元」池；再在预算内做精确动态规划： dp[c] = 花不超过 c 分钱能拿到的最好结果，按「目标份数 → 顺带餐品件数 → 顺带餐品原价」字典序比较。 优惠券是「只能用一次」的一次性道具，所以把问题拆成 max over 券子集 (券收益 + 无券无限背包)，两部分都保证最优，合起来仍是全局最优。 开会员卡是一条独立分支：卡费先从预算里扣，会员价单元共享「每日共 2 次」的额度 （分层 DP：第 k 层 = 已用 k 次额度），开卡与不开卡各求一次最优再比较， 并给出卡费回本线。 页面上所有价格来自麦当劳 MCP 接口，不是模型估算；卡费是唯一需要你填的数（接口不返回）。
